Участки

Импорт на этом устройстве. Принимаются проверенные контуры WGS84 с кадастровым номером.

№ на картеКадастровый номерПлощадь, га
По полученным контурам

Номера идут по соседству на карте. У многоконтурного участка все части имеют один номер; площадь включает все части. Это кадастровая площадь, а не площадь обработки. Для трёх участков без координат положение и площадь пока неизвестны.

Участки без контура

Для этих номеров пока не получены координаты и площадь. В исходном PDF указаны только номера и сведения о регистрации.

Архив возвращает HTTP 503, прямая карта НСПД недоступна. Это не означает, что границы не зарегистрированы. Для завершения нужны имеющиеся ЕГРН/КПТ с координатами и площадью.

Кадастр и поле — разные объекты

Показаны архивные кадастровые контуры. Источник и дата указаны в карточке участка. Фактически обрабатываемые части уточняются с Амиром.
