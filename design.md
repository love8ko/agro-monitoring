# Agro monitoring: Garden

Shared system for the four existing pages. Source of truth: tokens.css and site.css.

- Editorial, Garden, warm oat surfaces with green ink, no ornamental textures.
- Vollkorn 600 for headings, locally hosted with OFL. System sans for Cyrillic body
  and labels. Monospace is reserved for code and file formats.
- The existing farm image stays in the homepage header. Real Sentinel imagery
  leads the main content; scientific maps keep their original colours.
- Homepage: split introduction, season, instruments, drone observations, process,
  costs, materials, next step. Original facts, prices, images and links stay.
- Reference pages: reading column plus section index, native disclosure on phones.
- No load animation. Existing map dates, NDVI/RGB selection and swipe comparison stay.
- Buttons: one primary green pill; quiet secondary with a single outline. 48px minimum.
- Focus rings and reduced motion are explicit. Tables stack with their own field
  labels on phones. Light and dark OS preferences remain supported.
- No forms, external trackers, generated claims, or additional services introduced.
